# Submission checklist

- [ ] Confirm both team members' names and identifiers.
- [ ] Obtain/confirm permission to use the real traffic dataset; document source and license.
- [ ] If no real dataset is available, clearly state that results are synthetic-demo only.
- [ ] Create a **private** GitHub repository.
- [ ] Upload source, README, requirements, and dataset (only if its license permits redistribution).
- [ ] Invite faculty and assigned TA accounts with the required access.
- [ ] Run `pip install -r requirements.txt` and `python src/train.py` on a clean environment.
- [ ] Inspect generated metrics; do not invent or manually edit results.
- [ ] Update the report and slides with measured results only when real data is used.
- [ ] Add screenshots of successful training, comparison metrics, and prediction/dashboard.
- [ ] Rehearse a 3–5 minute explanation and divide contributions fairly.
